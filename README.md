## Deploy on GitHub Pages

1. Go to https://github.com/new
2. Repo name: **`raihan-patwary.github.io`** (exact — becomes your URL)
3. **Public** → **Create repository**
4. Click **"uploading an existing file"**, drag in ALL files (the .html, all images, your CV PDF, and hero-bg.jpg if you have it)
5. **Commit changes**
6. **Settings → Pages**, branch **main**, **Save**
7. Live in 1–2 min at **https://raihan-patwary.github.io**
